FIX 2 — CRITICAL: ADA flag wrong on Room ID w/Insert
         (ada_required=No is a code violation)
════════════════════════════════════════════════
Per 2010 ADA §703 and MA 521 CMR §41:
ALL permanently designated interior room signs
require tactile characters and Grade 2 Braille —
INCLUDING signs with changeable insert panels.

The insert panel holds the occupant name (which
changes). The tactile room number/type text is
PERMANENT and MUST be tactile + Braille.

Fix in Summary tab XLSX and Pricing tab:
  'Room ID'          → ADA Required: Yes
  'Room ID w/Insert' → ADA Required: Yes ← fix this
  'Restroom'         → ADA Required: Yes
  'Stair (Corridor)' → ADA Required: Yes
  'Stair (Landing)'  → ADA Required: Yes
  'Exit (Tactile)'   → ADA Required: Yes
  'Max Occupancy'    → ADA Required: No  ← informational
  'Evacuation Map'   → ADA Required: No  ← informational
  'Office Directory' → ADA Required: No  ← informational
  'Exit'             → ADA Required: No  ← illuminated sign

Also update the Pricing tab material defaults:
Room ID w/Insert → same ADA-compliant material 
as Room ID (Rowmark or equivalent with Braille).

Current logic only assigns Exit when it finds
an explicit EXIT room or vestibule. That's wrong.

Exit signs (illuminated, IBC §1011) are required
at EVERY exit access door leading to:
  - A stair enclosure
  - An exterior exit door
  - A horizontal exit

Rule R9 fix — assign Exit signs by location,
not by room name:

  For each stair identified:
    Add 1× Exit sign per floor per stair door
    (the door FROM corridor INTO stair)
    Fox Hill: 4 stairs × 2 floors = 8 exit signs

  For each exterior exit door (ground floor):
    Add 1× Exit sign
    Fox Hill: estimate 4 exterior exits minimum
    (main entry, gym exit, kitchen exit, community)

  Total minimum: 12 Exit signs
  Store these as floor=LEVEL N, room=STAIR X DOOR

Do NOT assign Exit to random rooms by name.
Exit signs are at DOORS, not rooms.
