FIX 1 — STAIR SIGNS (R11) — all building types
════════════════════════════════════════════════
Stair signs are missing across ALL building types.
Root cause: stair rooms are being filtered out
by room number validation before R11 runs.

UNIVERSAL stair detection — a room isStair=true
when ANY of these match:
  room_name contains: STAIR, STAIRWAY, STAIRWELL,
    FIRE STAIR, EXIT STAIR, STAIRS
  OR room_number matches these per building type:

  Education:   /^S[ABCD]\d{2}$/  (SA01, SB02)
  Healthcare:  /^S[ABCDE]\d{2}$/ OR /^ST\d{2,3}$/
  Commercial:  /^S\d{1,2}$/ OR /^STAIR-?\d+$/
  Government:  /^S\d{1,2}$/ OR /^STAIR[A-Z]$/
  Hotel:       /^S\d{1,2}$/ OR /^STAIR-?\d+$/
  Residential: /^S\d{1,2}$/ OR /^STAIR-?\d+$/
  Assembly:    /^S\d{1,2}$/ OR /^[A-Z]{1,2}-S\d+$/
  Unknown:     any room_name containing "STAIR"

NEVER filter out rooms matching stair patterns.
Add all stair patterns to the valid_room_patterns
allowlist for each building type.

R11 sign assignment when isStair=true:
  Per floor served by that stair:
    +1 Stair Identification (Corridor)
    +1 Stair Identification (Landing)

  Floors served = job.floor_count (default)
  If only 1 floor: 1 corridor + 1 landing only

Stair sign content by building type:
  Education:   "STAIR [X] — [NO/FIRE DEPT] ROOF ACCESS"
  Healthcare:  "STAIR [X]" + smoke compartment note
  Government:  "STAIR [X]" + Area of Rescue instruction
  Assembly:    "STAIR [X]" + Area of Rescue instruction
  All others:  "STAIR [X]"

Store stair variant in sign notes field.

Expected minimums per building type:
  Education 2-floor:    16 stair signs (4 stairs)
  Healthcare 4-floor:   16+ stair signs
  Commercial 3-floor:   12+ stair signs  
  Government 3-floor:   12+ stair signs
  Hotel 5-floor:        20+ stair signs
  Residential 4-floor:  16+ stair signs
  Assembly single:      4-8 stair signs
  Unknown:              flag count for review

FIX 2 — ADA REQUIRED FLAG — all sign types,
         all building types
════════════════════════════════════════════════
Per 2010 ADA §703 and IBC §1110:
ALL permanently designated interior room signs
require tactile characters + Grade 2 Braille.
This applies in ALL jurisdictions as minimum.

Update ada_required in BOTH Summary sheet and
Pricing tab for every building type:

  ada_required = YES:
    Room ID
    Room ID w/Insert       ← currently wrong (No)
    Restroom (all variants)
    Stair (Corridor)
    Stair (Landing)
    Exit (Tactile)
    Area of Rescue
    Elevator / In Case of Fire
    Boys / Girls / Men / Women
    Unisex Restroom
    Family Restroom
    BDA Location Sign
    Unit ID (Residential)  ← centered on door
    Patient Room ID (Healthcare)
    Courtroom ID (Government)

  ada_required = NO:
    Max Occupancy          ← informational only
    Evacuation Map         ← graphic/informational
    Office Directory       ← directory, not room ID
    Exit (illuminated)     ← electrical, not tactile
    LEED Signs             ← decorative
    Exterior Signs         ← different standard

Note for Residential and Hotel:
  Unit/guest room signs are ADA tactile BUT
  mounting location = centered on door
  (not latch side) per ADA §703.4.2 exception.
  Store as ada_required=Yes, mount_side='center'

FIX 3 — EXIT SIGNS (R9) — all building types
════════════════════════════════════════════════
Exit signs are door-based not room-based.
Current logic misses 70%+ of required exits.

Universal R9 logic:
  Exit signs are ALWAYS derived from stair count
  and exterior door count — never from room names.

  Formula per building type:

  EDUCATION (Group E):
    (stair_count × floor_count) +
    exterior_exit_doors (min 2 per wing per floor)
    Minimum: 12 for 2-story, 2-wing school

  HEALTHCARE (Group I-2):
    (stair_count × floor_count) +
    (smoke_compartment_count × 2) +
    exterior_exit_doors
    Minimum: 16 for 4-story hospital

  COMMERCIAL (Group B):
    (stair_count × floor_count) +
    exterior_exit_doors (min 2 per floor)
    Minimum: 8 for 3-story office

  GOVERNMENT (Group B/A):
    Same as Commercial +
    secure zone exit doors
    Minimum: 10 for 3-story courthouse

  HOTEL (Group R-1):
    (stair_count × floor_count) +
    exterior_exit_doors
    Minimum: 12 for 5-story hotel

  RESIDENTIAL (Group R-2):
    (stair_count × floor_count) +
    exterior_exit_doors (min 2 per building)
    Minimum: 8 for 4-story apartment

  ASSEMBLY (Group A):
    HIGHER multiplier — IBC 1006.3 Group A
    (stair_count × floor_count × 1.5 rounded up) +
    exterior_exit_doors (min 3 per assembly space)
    Minimum: 12 for single-story arena/theater

  UNKNOWN:
    Use Commercial formula as conservative default

Implementation:
  When stair rooms are extracted (Fix 1),
  automatically create Exit sign records:
    For each stair × each floor:
      { signType: 'Exit', location: 'Stair [X] 
        door at Level [N]', rule: 'R9' }
  
  Plus add minimum exterior exit doors:
    { signType: 'Exit', location: 'Exterior 
        exit door [N]', rule: 'R9',
        notes: 'Verify count on plans' }

  Show exit signs in Review tab under a new 
  "Egress" section, separate from room signs.

FIX 4 — EVACUATION MAP DENSITY (R13)
         all building types
════════════════════════════════════════════════
Evacuation Maps go at decision points only.
Never one per room. Never one per alcove.

Max Evacuation Maps per floor by building type:
  Education:   2 per floor (one per wing if 2-wing)
  Healthcare:  4 per floor (one per smoke compartment)
  Commercial:  2 per floor
  Government:  2 per floor
  Hotel:       1 per floor (at elevator lobby)
  Residential: 1 per floor (at elevator/stair lobby)
  Assembly:    2 per floor (at main entries)
  Unknown:     2 per floor

Placement rules (all types):
  ASSIGN to: main CORRIDOR, LOBBY, ELEVATOR LOBBY,
    primary stair landing (one per stair)
  DO NOT assign to: PROJECT AREA, PASSAGE, ALCOVE,
    VESTIBULE, individual offices, classrooms,
    storage rooms, or any non-corridor space

Store evac_map_max_per_floor in 
building_type_profiles table.
Rules engine enforces the cap — once max is 
reached for that floor, stop assigning.
