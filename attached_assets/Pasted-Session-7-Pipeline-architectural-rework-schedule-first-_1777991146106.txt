Change 5 — Sort XLSX output by room number within each floor
In exports.ts, sort signs before writing to XLSX:
typescript// Sort by floor level, then by room number within each floor
signs.sort((a, b) => {
  const levelA = a.level ?? "Unspecified";
  const levelB = b.level ?? "Unspecified";
  if (levelA !== levelB) return levelA.localeCompare(levelB);
  
  // Natural sort on room number so A100 < A101 < A200 < B100
  const roomA = a.message?.split(" | ")[0] ?? "";
  const roomB = b.message?.split(" | ")[0] ?? "";
  return roomA.localeCompare(roomB, undefined, { numeric: true });
});
This makes duplicate detection instant — if Room A209 appears twice, the estimator sees it immediately.
