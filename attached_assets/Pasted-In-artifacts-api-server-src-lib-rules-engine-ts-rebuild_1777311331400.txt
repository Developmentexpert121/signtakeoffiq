STEP 2 — Auto-detect when Unknown selected:

- 30%+ rooms are UNIT/APT → residential
- Contains CLASSROOM, GYMNASIUM, CAFETERIA → education
- Contains PATIENT ROOM, ICU, WARD, 
  OPERATING ROOM → healthcare
- Contains COURTROOM, COUNCIL CHAMBER → government
- Contains GUEST ROOM + FRONT DESK + LOBBY → hotel
- Contains AUDITORIUM, SANCTUARY, NAVE → assembly
- Default → commercial

STEP 3 — Rule matrix per building type:

COMMERCIAL:
- Room ID: all enclosed rooms except corridors
- Restroom: all toilet rooms
- Exit: all exit doors
- Stair Corridor + Landing: all stairs
- Elevator: all elevators
- Evacuation Map: 1 per floor
- Office Directory: only if 3+ suites OR 30+ rooms 
  with lobby
- Max Occupancy: conference/dining/meeting rooms only
- Unit ID: NEVER

RESIDENTIAL:
- Unit ID: every UNIT/APT/SUITE entrance
- Room ID: common areas only (lobby, mail room,
  laundry, gym, leasing office, package room,
  community room, fitness center)
- Restroom: common area restrooms only
- Exit: all exit doors
- Stair Corridor + Landing: all stairs
- Elevator: all elevators
- Evacuation Map: 2 per floor
- Max Occupancy: gym/community room only
- Office Directory: NEVER

EDUCATION:
- Room ID: ALL rooms (classrooms, labs, offices,
  storage, mechanical, custodial)
- Restroom: all toilet rooms
- Exit: all exit doors
- Stair Corridor + Landing: all stairs
- Elevator: all elevators
- Evacuation Map: 1 per floor
- Max Occupancy: gymnasium, auditorium, cafeteria only
- Unit ID: NEVER
- Office Directory: NEVER

HEALTHCARE:
- Room ID: ALL rooms (patient rooms, exam rooms,
  labs, offices, storage, mechanical)
- Restroom: all toilet rooms
- Exit: all exit doors
- Stair Corridor + Landing: all stairs
- Elevator: all elevators
- Evacuation Map: 2 per floor
- Max Occupancy: waiting rooms, assembly areas
- Unit ID: NEVER

GOVERNMENT:
- Room ID: ALL rooms
- Restroom: all toilet rooms
- Exit: all exit doors
- Stair Corridor + Landing: all stairs
- Elevator: all elevators
- Evacuation Map: 1 per floor
- Office Directory: if public lobby present
- Max Occupancy: courtrooms, chambers, assembly rooms
- Unit ID: NEVER

HOTEL:
- Unit ID: every guest room (KING, QUEEN, SUITE + 
  number, GUEST ROOM, ROOM + number)
- Room ID: common areas (lobby, restaurant,
  conference, spa, fitness, business center,
  ballroom, pool, bar)
- Restroom: public restrooms only
- Exit: all exit doors
- Stair Corridor + Landing: all stairs
- Elevator: all elevators
- Evacuation Map: 2 per floor
- Max Occupancy: dining, conference, ballroom

ASSEMBLY:
- Room ID: all permanent spaces
- Restroom: all toilet rooms
- Exit: all exit doors
- Stair Corridor + Landing: all stairs
- Elevator: all elevators
- Evacuation Map: 2 per floor
- Max Occupancy: main hall, sanctuary, auditorium,
  all assembly spaces
- Accessible Entrance: always required
- Unit ID: NEVER
