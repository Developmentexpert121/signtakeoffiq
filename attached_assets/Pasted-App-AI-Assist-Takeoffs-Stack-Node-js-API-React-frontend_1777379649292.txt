FIX 1 — Process ALL pages of the uploaded PDF

selection logic must:

1. First pass: extract text from ALL pages to 
   build a sheet index. For each page, extract 
   the title block text (bottom-right corner)

2. Identify signage-relevant pages by matching

   - "signage plan", "sign plan", "signage"

3. If dedicated signage sheets exist (title

4. If NO dedicated signage sheets, fall back to 
   all floor plan sheets.

FIX 2 — Fix garbled room name extraction
══════════════════════════════════════════════════
In the room extraction step, the PDF text parser 
is reading annotation reference strings 
(e.g. "W139.1", "19A", "MB 8'-0''") as room 
names. These are drawing callouts, not room labels.

Fix the room label extraction filter:
- Room labels are CAPS text adjacent to a 
  room number (3–4 digit format like W139, E119)
- REJECT strings matching these patterns:
  - Pure coordinate references: "W123.1", "E100.2"  
    (room_number + "." + digit)
  - Dimension strings: "8'-0''", "6'-0''"
  - Sign legend codes: "MB", "TB", "CB" followed 
    by dimension
  - Drawing grid refs: single letter + number 
    like "A.1", "K.4"
  - Strings containing only numbers, dashes, 
    quotes, or dimension tokens

- ACCEPT strings that are:
  - ALL CAPS words (2+ letters): "CLASSROOM", 
    "CORRIDOR", "GYMNASIUM", "MECHANICAL"
  - Known room-type vocabulary (load from the 
    existing room-type dictionary)
  - Room number + room name pairs where name 
    is ≥ 3 alphabetic characters
