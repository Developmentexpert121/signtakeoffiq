Fix 2 — Marker culling bug: all markers should be visible at 30% zoom without hitting FIT.
The current Branch 3 viewport culling is hiding markers that are within the visible canvas area. Root cause: the visibleMarkers useMemo fires before imgSize is known, computes pixX/pixY = 0 for all markers, and the viewport check fails because (0,0) is outside the visible bounds at 30% zoom after the initial pan.
Replace Branch 3 with this corrected logic:
typescript// Branch 3 — Individual mode (displayScale >= _CLUSTER_ZOOM)
// If imgSize not yet known, return all signs up to cap — same as pre-transform path
if (!imgSize) {
  return sheetSigns
    .filter(s => !s.isDeleted)
    .slice(0, _MAX_MARKERS)
    .map(s => ({ type: 'individual' as const, sign: s }))
}

// imgSize is known — do real viewport culling
const containerW = containerRef.current?.clientWidth ?? 800
const containerH = containerRef.current?.clientHeight ?? 600

// Convert each sign's 0–100,000 coords to natural image pixels
// then check if that pixel falls within the current viewport
// Viewport in image-pixel space:
const vLeft   = (-panOffset.x - containerW * 0.15) / displayScale
const vRight  = (-panOffset.x + containerW * 1.15) / displayScale
const vTop    = (-panOffset.y - containerH * 0.15) / displayScale
const vBottom = (-panOffset.y + containerH * 1.15) / displayScale

const inView = sheetSigns.filter(s => {
  if (s.isDeleted) return false
  // Signs with sentinel coords (50000, 50000) or null — always include
  // so they show in tray and can be dragged; exclude from canvas render
  const x = s.markerX ?? 50000
  const y = s.markerY ?? 50000
  if (x === 50000 && y === 50000) return false  // unplaced — don't render on canvas
  const pixX = (x / 100000) * imgSize.w
  const pixY = (y / 100000) * imgSize.h
  return pixX >= vLeft && pixX <= vRight && pixY >= vTop && pixY <= vBottom
})

// Always include the actively dragged/selected sign even if off-viewport
const selected = sheetSigns.find(s => s.id === selectedSignId)
const candidates = selected && !inView.find(s => s.id === selected.id)
  ? [...inView, selected]
  : inView

return candidates
  .slice(0, _MAX_MARKERS)
  .map(s => ({ type: 'individual' as const, sign: s }))
