════════════════════════════════════════════════
Current behavior: when a sign schedule file is
uploaded, the pipeline switches to schedule-import
mode and skips room extraction entirely.

This is wrong. Both must always run:
  1. Room extraction from floor plans (always)
  2. Schedule import (if schedule file exists)
     → used to supplement, not replace rooms

Fix in pipeline.ts — remove the mode switch:

  // WRONG — current behavior:
  if (hasSignScheduleFile) {
    return runScheduleImportMode(job);
    // ← skips room extraction entirely
  }

  // CORRECT — always run both:
  // Step 1: Always extract rooms from floor plans
  const rooms = await extractRoomsFromPlans(job);
  
  // Step 2: If schedule file exists, use it to
  // supplement/validate room extraction

    // Merge: schedule items take priority for

      rooms, scheduleItems, jobId
    );
  } else {
    await saveRooms(jobId, rooms);
  }
