CHANGE 1 — Upgrade coordinate grid: 1000 → 100000
══════════════════════════════════════════════════
The current 0–1000 integer grid causes rounding 
errors up to 0.1% per axis. Upgrade to 0–100000.

In the Python PDF sidecar:
  normX = round((label_center_x / page_width)  × 100000)
  normY = round((label_center_y / page_height) × 100000)
  + 3% downward nudge stays: normY += round(0.03 × 100000)

In the vision-estimated path (Claude or Gemini):
  x = percentage_guess × 1000  (was × 10)
  y = percentage_guess × 1000

In the React frontend marker renderer:
  pixelX = (markerX / 100000) × imageWidth
  pixelY = (markerY / 100000) × imageHeight

In the DB: if x/y columns are INTEGER, ALTER to 
BIGINT. If stored as normalized floats (0.0–1.0), 
no DB change needed — just update the math.

Verify: a marker at the center of a 2000×1500px 
image should land at exactly (1000px, 750px).

CHANGE 2 — Fix PDF native coordinate alignment
══════════════════════════════════════════════════
PDF native coords are calculated against raw PDF 
page dimensions, but the rendered PNG may have 
been cropped, padded, or scaled differently.

In the Python PDF sidecar, when rasterizing the PDF:
1. Record the EXACT pixel dimensions of the output PNG
2. Record any margins/padding added during rasterization
3. Pass these back with each coordinate:
   {
     "normX": 45231,
     "normY": 31820,
     "coordSource": "pdf_native",
     "renderWidth": 3400,
     "renderHeight": 2200,
     "renderOffsetX": 0,   ← pixels of left padding
     "renderOffsetY": 0    ← pixels of top padding
   }

In the Node API, when saving pdf_native coords:
  Adjust for offset before storing:
  adjustedX = round((labelCenterX - offsetX) / 
               renderWidth × 100000)
  adjustedY = round((labelCenterY - offsetY) / 
               renderHeight × 100000)

This eliminates systematic drift where all markers 
are shifted in the same direction.

CHANGE 4 — Improve the downward nudge heuristic
══════════════════════════════════════════════════
The fixed 3% nudge is too blunt. Replace with a 
room-size-aware nudge:

  If room bounding box height is known from PDF:
    nudge = roomHeight × 0.35  ← 35% into the room
  Else (vision estimated, no bbox):
    nudge = 0.025 × imageHeight  ← 2.5% fixed

This keeps markers inside the room for both 
large conference rooms and small closets.
