MARKER PLACEMENT FROM PIPELINE
═══════════════════════════════
When pipeline detects a room, store the 
x/y coordinates from the PDF text extraction:

In pipeline.ts, when extracting room text:
- Store the bounding box center of the room 
  number text as the marker position
- Convert PDF coordinates to % of page:
  markerX = (bbox.x + bbox.width/2) / pageWidth
  markerY = (bbox.y + bbox.height/2) / pageHeight
- Store as: room.markerX, room.markerY (0-1 range)

When rendering on PNG:
  pixelX = markerX × imageWidth
  pixelY = markerY × imageHeight

This gives native PDF-coordinate accuracy for 
markers instead of AI vision guesses.

For rooms without coordinates (AI vision rooms):
  Show marker in center of detected region
  Display with dashed border (needs confirmation)

Human-corrected marker positions:
  When user drags a marker to new position:
  - Save new x/y as room.markerX, room.markerY
  - Set room.markerSource = 'human_corrected'
  - These are never overwritten by pipeline rescans
  - Feed back to training for future accuracy
