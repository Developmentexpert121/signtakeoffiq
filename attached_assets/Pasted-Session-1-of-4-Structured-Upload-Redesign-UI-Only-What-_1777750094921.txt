Step 2 — Create StructuredUploader.tsx
Create artifacts/web/src/components/StructuredUploader.tsx. This component replaces the overview card upload section. It receives the same props as DualZoneUploader plus buildingType and jobId.
The component renders three slot cards stacked vertically. Each slot card contains:

Slot header with icon, title, and required/optional badge
Plain English description
The existing DualZoneUploader component scoped to that slot's fileCategory
A floor label prompt box (Slot 1 only)
A dismiss-able yellow warning banner if the slot classifier fires (placeholder for Session 2)

Slot 1 — Floor Plans

Title: "Floor Plans"
Badge: "Required" (amber)
Description: "The pages showing the layout of each floor with room names and door locations labeled. These are the bird's-eye view pages."
fileCategory: "floor_plan"
Floor label input: small text field below the uploader — label: "What floors does this contain?", placeholder: "e.g. First floor, or Floors 1–3"
Store floor label in component state, pass to parent via onFloorLabelChange callback

Slot 2 — Room or Finish Schedule

Title: "Room or Finish Schedule"
Badge: "Recommended" (blue)
Description: "The page listing all rooms with finish information. Significantly improves room name accuracy. Often labeled A-7xx."
fileCategory: "room_schedule" — add this as a new accepted value alongside existing categories
Below the uploader, show the roomScheduleHint from the building type's uploadGuide

Slot 3 — Sign Schedule or Specs

Title: "Sign Schedule or Specs"
Badge: "Optional" (gray)
Description: "The sign specification document describing sign types, materials, and mounting requirements. Usually Division 10 14 00 in the spec book."
fileCategory: "sign_schedule" — already exists in the codebase
Below the uploader, show the signScheduleHint from the building type's uploadGuide

Building type tooltip ("i" button)

Render a small info icon button at the top of the component, next to a heading: "Upload Construction Documents"
On click, open a popover (use the existing Popover component from @/components/ui/popover)
Popover content shows two sections for the selected building type's uploadGuide:

Look for: bulleted list of lookFor items
Avoid uploading: bulleted list of avoid items


If buildingType is not set or has no uploadGuide, show generic text

Progress checklist

Below the three slot cards, show a simple status list:

✅ / ○ Floor plans — shows file count if uploaded, "Not uploaded" if empty
✅ / ⚠️ Room schedule — shows "Uploaded" or "Not uploaded (recommended)"
✅ / ○ Sign schedule — shows "Uploaded" or "Not uploaded (optional)"


This is read-only display, derived from the files prop filtered by fileCategory

File size warning

When a file is added to any slot, check its size
Floor plan slot: if over 50MB, show inline warning: "This file is larger than expected for floor plans. If you've uploaded a full permit package, consider uploading only the floor plan pages (typically A-1xx sheets)."
Schedule slots: if over 20MB, show inline warning: "This file seems large for a schedule document."
Warning is informational only — does not block upload
