FIX 3 — Stair detection: universal patterns
         for all 8 building types
════════════════════════════════════════════════
Current detection misses stairs on some plan
styles. Different firms use different naming.
Make detection universal.

In detectStairCores(), replace the current query
with a comprehensive pattern that catches ALL
common stair naming conventions:

  SELECT COUNT(DISTINCT stair_core) as stair_count
  FROM (
    SELECT
      CASE
        -- Education: SA01, SB02, SC01, SD01
        WHEN room_number ~ '^S[A-F]\\d{2}[A-Z]?$'
          THEN REGEXP_REPLACE(room_number,'\\d+[A-Z]?$','')
        -- Numeric stair: S1, S2, S01, S02  
        WHEN room_number ~ '^S\\d{1,2}[A-Z]?$'
          THEN REGEXP_REPLACE(room_number,'\\d+[A-Z]?$','')
        -- Named stair room number: STAIR-1, STAIR-A
        WHEN room_number ~* '^STAIR-?[A-Z0-9]'
          THEN REGEXP_REPLACE(
            UPPER(room_number),'[^A-Z0-9]','','g')
        -- Room name contains STAIR
        WHEN room_name ~* '^STAIR(WAY|WELL)?\\s*[A-Z0-9]'
          THEN REGEXP_REPLACE(
            UPPER(room_name),'\\s+','_','g')
        WHEN room_name ~* 'STAIR'
          THEN REGEXP_REPLACE(
            UPPER(room_name),'\\s+','_','g')
        ELSE NULL
      END as stair_core
    FROM signs
    WHERE job_id = $1
    AND (
      room_number ~ '^S[A-F]\\d{1,2}'
      OR room_number ~* '^STAIR'
      OR room_name ~* 'STAIR'
    )
  ) cores
  WHERE stair_core IS NOT NULL;
