Change 6 — Sort XLSX output by room number within each floor
In exports.ts, sort signs before writing to XLSX:
typescriptsigns.sort((a, b) => {
  // Sort by floor level first
  const levelA = a.level ?? "Unspecified";
  const levelB = b.level ?? "Unspecified";
  if (levelA !== levelB) return levelA.localeCompare(levelB);
  
  // Then by room number naturally within each floor
  // so A100 < A101 < A200 < B100
  const roomA = a.message?.split(" | ")[0] ?? "";
  const roomB = b.message?.split(" | ")[0] ?? "";
  return roomA.localeCompare(roomB, undefined, { numeric: true });
});
