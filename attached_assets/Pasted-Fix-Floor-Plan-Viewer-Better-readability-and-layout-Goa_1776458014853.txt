To compute signTypeCounts, add this derived variable before the return statement in the viewer component:

// Build sign type → count + color map for legend

const signTypeCounts = useMemo(() => {

  const map = new Map<string, { count: number; color: string }>();

  for (const m of textMarkers.filter((m) => !m.isGhost)) {

    const sign = signsOnCurrentPage.find((s) => s.id === m.signId);

    const type = (sign?.signType as string) || "Room ID";

    const existing = map.get(type);

    if (existing) {

      existing.count++;

    } else {

      map.set(type, { count: 1, color: m.color });

    }

  }

  return Array.from(map.entries())

    .map(([type, { count, color }]) => ({ type, count, color }))

    .sort((a, b) => b.count - a.count);

}, [textMarkers, signsOnCurrentPage]);

Currently the page dropdown shows "pg 2", "pg 3" etc. which is confusing. Update it to show the sheet title when available.

In UnifiedPlanViewer.tsx, find where the page dropdown options are built. Look for where navigablePages maps to option labels. Update to prefer the sheet title from the manifest:

// When building the page label for the dropdown, prefer sheet title

const getPageLabel = (pageNum: number): string => {

  // Try to find a sheet title from file pageStats manifest

  const manifestRow = (file as any)?.pageStats?.manifest?.find(

    (r: any) => r.pdfPage === pageNum

  );

  if (manifestRow?.sheetTitle) return `${manifestRow.sheetTitle} (pg ${pageNum})`;

  const pageLabel = (file as any)?.pageStats?.pageLabels?.[pageNum - 1];

  if (pageLabel) return `${pageLabel} (pg ${pageNum})`;

  return `Floor plan page ${pageNum}`;

};
