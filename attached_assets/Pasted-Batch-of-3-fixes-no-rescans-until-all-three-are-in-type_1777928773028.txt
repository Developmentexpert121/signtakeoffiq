Fix 2 — Level replication schedule matching
In Step 9 schedule matching, replicated rooms (cloned to Levels 4/5/6 from AA103) are not getting schedule signs because the matcher only matches Level 3 source rooms.
Find the schedule-to-room matching logic in Step 9. When matching schedule entries to rooms, normalize the room number by stripping the floor prefix digit before comparing. For example, room number "A407" should match schedule entry "A307" if the base identifier after the floor digit matches ("07" in both cases... actually the full identifier minus the hundreds digit).
More precisely — for residential buildings, unit numbers follow the pattern [Wing][Floor][Unit] e.g. A307 = Wing A, Floor 3, Unit 07. A407 = Wing A, Floor 4, Unit 07. The schedule lists one entry per unit type (A307) but the replicated rooms have numbers A407/A507/A607.
Add a normalization function:
typescriptfunction normalizeUnitNumber(roomNum: string): string {
  // For residential unit numbers like A307, A407, B215 etc.
  // Strip the floor digit (position 1) to get the base unit: A07, B15
  const match = roomNum.match(/^([A-Z])(\d)(\d{2,})$/);
  if (match) return `${match[1]}${match[3]}`; // A + 07 = A07
  return roomNum;
}
In the schedule matching loop, try exact match first, then normalized match as fallback. Log when normalized matching fires:
