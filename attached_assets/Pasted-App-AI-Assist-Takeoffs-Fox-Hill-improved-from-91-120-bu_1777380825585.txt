FIX 1 — Strengthen garbled room name filter
══════════════════════════════════════════════════
Still seeing junk room names from PDF callouts 
e.g. "RY CT TA", ".1 .1 MB CO1RRIDOR", 
"- '0' SLP - 1. 1. 1W 1W UP MB MB"

Tighten the rejection filter — REJECT any 
room name where:
- Contains 3+ consecutive non-alpha characters
  e.g. ".1 .1", "'0'", "1W"
- Contains dimension tokens: any string matching
  \d+'-\d+'' or \d+X\d+ (like 60X21, 8'-0'')
- Contains drawing ref patterns: letter(s) + 
  digit + "." + digit (like W139.1, E100.2)  
- Token count > 5 AND >50% of tokens are 
  non-dictionary words
- Room number is truncated/partial: single 
  digit, single letter, or 2-char strings 
  like "W1", "E1", "M0", "V01", "Y12"

Valid room numbers for this project are:
- W/E prefix + 3 digits: W100–W999, E100–E999
- WC prefix + 3 digits: WC100, WC200
- SA/SB/SC/SD + 2 digits: stairs
- EV + 2 digits: elevators

Reject any room number that doesn't match 
these patterns.
