In artifacts/api-server/src/lib/ find the XLSX 
export generator and add a "Pricing" sheet tab.

The pricing data comes from tenant_pricing_settings 
table. If no tenant settings exist, use the MSRP 
defaults from the ADA pricing sheet.

ROW 3 — Column headers:
A: Sign Type
B: Size (W × H)
C: Sq Inches

F: Finishing

H: Finishing $/sq in
I: Total $/sq in
J: Unit Price
K: Extended Price
L: Notes

Header row: dark background (#1F2937), 
white bold, 10pt, centered

DATA ROWS — one per sign type from takeoff:
A: Sign type name (Room ID, Restroom, Exit etc)
B: Standard ADA size (6 × 6, 6 × 8 etc)
C: Sq inches (formula: =WIDTH*HEIGHT, calculated)
D: Qty (from takeoff — bold, editable, YELLOW fill)
E: Material name (from tenant default for this sign type)
F: Finishing name (from tenant default for this sign type)
G: Base cost/sq in (from tenant settings, gray text)
H: Finishing cost/sq in (from tenant settings, gray text)
I: Total $/sq in (formula: =G+H, gray text)
J: Unit Price (formula: =MAX(min_price, C*I))
   YELLOW fill — estimator can override
K: Extended Price (formula: =D*J, bold)
L: Notes (blank, editable, YELLOW fill)

FORMATTING:
- Freeze rows 1-3
- Yellow cells (#FFFBEB): D (qty), J (unit price), L (notes)
  These are clearly editable by estimator
- Gray cells: E, F, G, H, I
  These come from tenant settings (read-only reference)
- Currency format: G, H, I, J, K → $#,##0.00
- Borders: thin gray on all data cells
- Font: Calibri 11pt throughout
- Auto-filter on row 3

TENANT SETTINGS INTEGRATION:
When generating the XLSX:
1. Query tenant_pricing_settings for current tenant
2. For each sign type, look up:
   - sign_defaults[signType].material → material name + cost
   - sign_defaults[signType].finishing → finishing name + cost  
   - additional_charges.minSignPrice → for MAX formula
3. If no tenant settings found, use MSRP defaults above
4. Log: "Pricing tab: using [tenant/MSRP default] pricing"
