```ts

accuracyScore: text("accuracy_score"), // stored as decimal string e.g. "0.9315"

```

Generate and run the migration.

**API changes — `training.ts`:**

In the `POST /training/import/confirm` route, calculate and store accuracy score when saving the snapshot:

```ts
// Accuracy = matchedCount / (matchedCount + aiMissedCount + aiExtraCount)
// Store as decimal string with 4 decimal places
const total = resolvedMatchedCount + resolvedAiMissedCount + resolvedAiExtraCount;
const accuracyScore = total > 0 
  ? (resolvedMatchedCount / total).toFixed(4) 
  : null;
```

Add `buildingType`, `jurisdiction`, `accuracyScore`, and `totalHumanSigns` to the `req.body` destructure and pass them into the `db.insert(importSnapshotsTable)` call.

Also add `accuracyScore`, `buildingType`, `jurisdiction` to the snapshot response in `GET /training/snapshots` and `GET /training/override-impact`.
