  \|createJob.*then.*scan\|job.*created.*scan" \

Fix: pipeline should only start when the user
explicitly clicks Process or Rescan.
It should NEVER auto-start from:
  - Job creation callback
  - Page load / useEffect
  - Status polling detecting 'pending' state
  - File upload completion

The ONLY valid triggers for pipeline start:
  1. User clicks "Process" button (new job)
  2. User clicks "Rescan" button (existing job)
  3. User clicks "Retry" button (failed job)

Add a guard at the pipeline entry point:
  if (!req.body.userInitiated) {
    console.error('[PIPELINE] Blocked auto-start',
      'for job', jobId);
    return res.status(400).json({
      error: 'Pipeline must be user-initiated'
    });
  }

And in the frontend, ensure the Process/Rescan/
Retry buttons all pass userInitiated: true
in their API payload.
