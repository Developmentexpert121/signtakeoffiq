FIX 1 — Classify ALL sheet types correctly
         Applies to ALL building types
════════════════════════════════════════════════
Update the sheet classification step (Step 4b)
to recognize 5 distinct sheet types:

  const SHEET_TYPES = {
    FLOOR_PLAN: 'floor_plan',
    SIGN_SCHEDULE: 'sign_schedule',
    SIGN_DETAILS: 'sign_details',
    SPECIALTY_SIGNAGE: 'specialty_signage',
    EGRESS: 'egress',
    MOUNTING_HEIGHTS: 'mounting_heights',
  };

  function classifySheet(title, sheetNumber) {
    const t = title.toLowerCase();
    
    // Floor plans — room extraction
    if (t.includes('floor plan') || 
        t.includes('signage plan') ||
        t.includes('sign plan'))
      return SHEET_TYPES.FLOOR_PLAN;
    
    // Sign schedules — plaque type extraction
    if (t.includes('sign schedule') ||
        t.includes('plaque schedule') ||
        t.includes('signage schedule'))
      return SHEET_TYPES.SIGN_SCHEDULE;
    
    // Sign details — specialty item extraction
    if (t.includes('sign detail') ||
        t.includes('signage detail') ||
        t.includes('enlarged') ||
        t.includes('wallcovering') ||
        t.includes('graphic') ||
        t.includes('exterior sign') ||
        t.includes('site sign'))
      return SHEET_TYPES.SIGN_DETAILS;
    
    // Specialty signage — branded/decorative
    if (t.includes('wall covering') ||
        t.includes('wallcovering') ||
        t.includes('interpretive') ||
        t.includes('wayfinding') ||
        t.includes('branding'))
      return SHEET_TYPES.SPECIALTY_SIGNAGE;
    
    // Egress sheets
    if (t.includes('egress') ||
        t.includes('life safety') ||
        t.includes('occupant load'))
      return SHEET_TYPES.EGRESS;
      
    return null; // unknown — flag for review
  }

Process ALL classified sheets — not just
FLOOR_PLAN type. Each type has different
extraction logic (see Fix 2).

FIX 2 — Extract specialty items from detail sheets
         Store separately from room signs
════════════════════════════════════════════════
For SIGN_DETAILS and SPECIALTY_SIGNAGE sheets,
run Gemini with a different extraction prompt:

SPECIALTY_EXTRACTION_PROMPT:
"""
You are reading an architectural signage detail
or specialty signage sheet.

Extract every distinct sign item shown with:
- sign_description: what the sign says or depicts
- sign_type: one of [exterior_letter, 
    dimensional_letter, wall_graphic, 
    interpretive_sign, acrylic_panel,
    site_sign, wayfinding, other]
- quantity: number shown on drawing
- dimensions: size if shown (e.g. "18x36")
- location: where it goes (e.g. "Entry Canopy",
    "Gymnasium Exterior", "Stair A")
- notes: any spec references, materials, fonts

Return ONLY valid JSON:
{
  "specialty_items": [
    {
      "sign_description": "FOX HILL SCHOOL",
      "sign_type": "dimensional_letter",
      "quantity": 1,
      "dimensions": "varies",
      "location": "Entry Canopy",
      "notes": "1\" thick cut aluminum, Avenir Light"
    }
  ]
}

DO NOT include standard ADA room ID signs.
DO NOT include exit signs or restroom signs.
ONLY include specialty, exterior, dimensional,
graphic, or decorative sign items.
"""

Store results in a new table:
  specialty_signs (
    id, job_id, sign_description, sign_type,
    quantity, dimensions, location, notes,
    source_sheet, confidence, created_at
  )
